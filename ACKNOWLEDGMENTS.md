# Acknowledgments and Attribution

## Dataset

This project uses the public **LeapGestRecog** dataset distributed on Kaggle as:

`gti-upm/leapgestrecog`

The dataset contains near-infrared hand-gesture images captured with a Leap Motion sensor.

## Starter code

The CYBR 422 team project began from an open-source Kaggle notebook/code example associated with the dataset. The course team adapted and extended that starting point. This repository therefore does **not** claim that every line or concept originated with the student team.

Project-specific work included correcting the gesture-to-class mapping, reorganizing data handling, training/evaluating the model, and integrating an explainability component.

## Team project

This originated as a three-person academic project.

The repository owner's documented contributions were:
- most of the main model codebase;
- dataset organization and class-label correction;
- project brainstorming; and
- the final presentation.

The SHAP explainability component was primarily developed by another team member and integrated into the shared final notebook.

## Why this file exists

The goal of this repository is to present the work professionally **without overstating authorship or results**. Third-party datasets, starter code, and collaborative contributions are explicitly acknowledged.
